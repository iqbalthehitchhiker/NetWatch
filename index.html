NetWatch
Network Monitoring Trainer
NetWatch teaches you to monitor, analyze and diagnose a network — not to build or configure one. Every lesson loads a predefined network, plays out a scripted incident, and asks you to find the root cause using only the evidence a monitoring engineer would actually have: telemetry, topology state and packet captures.
Select lesson→ Choose mode→ Observe network→ Detect anomaly→ Investigate evidence→ Diagnose
All topologies below are predefined — NetWatch is a monitoring simulator, not a topology editor. All telemetry and packet data are simulated/mock for educational purposes; nothing here touches a real network.

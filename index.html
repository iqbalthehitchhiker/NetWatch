NetWatch
Network Monitoring Trainer

NetWatch is a network monitoring simulator for learning how to read a live network dashboard and diagnose faults. Each lesson loads a predefined network, plays out a scripted incident in real time, and asks you to identify the root cause from the evidence in front of you — the same evidence a monitoring engineer would actually have.

You are not configuring or building anything. You are watching, interpreting, and diagnosing.

What is a lesson?

A lesson is a fixed scenario: a network topology (a set of connected devices) and a scripted incident that unfolds over time. The simulation runs second by second — metrics change, alerts fire, and the packet capture fills with evidence. Your job is to watch the dashboard, spot the anomaly, and submit a diagnosis from the multiple-choice options provided.

Two modes
📖 Teach Mode

No login, no scoring, no attempt limit. Use this to learn the concepts before being assessed.

  • Click any device, metric card, alert, or packet row to open an Explain Panel — a plain-language description of what that element is and what it indicates about network health.
  • All hints are available, one at a time.
  • After you submit a diagnosis, the full explanation is shown automatically.
📝 Quiz Mode

Requires a student login. Results are recorded server-side against your identity.

  • The Explain Panel is hidden — you must reason from the simulation evidence alone.
  • Only the first hint is available.
  • Attempts are limited per lesson. An instructor can reset your counter if needed.
What you will see inside a lesson
The simulation dashboard has six tabs. You do not need all of them for every lesson — part of the skill is knowing where to look.
Stat Bar
Six live counters across the top: healthy device count, active alerts, average latency, average CPU, packet loss, and elapsed time.
Overview
Rolling charts for traffic, CPU, and latency, plus a card for each device showing its current health status.
Topology
An SVG diagram of the network. Link colours shift from green → amber → red as latency and packet loss rise. Click a node to inspect its metrics.
Alerts
A timestamped list of critical and warning events fired by the incident script as the simulation runs.
Packets
A simulated packet capture. Flagged rows (red) contain anomalous traffic matching the incident pattern — protocol, direction, and info field are all evidence.
Metrics / Logs
Per-device telemetry snapshot, link quality stats, and a running event log with timestamps you can use to reconstruct the incident timeline.
